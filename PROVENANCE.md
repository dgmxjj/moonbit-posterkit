# Provenance

## Project Origin

`moonbit-posterkit` is an original project created for the MoonBit August 2026 hackathon track.
The codebase was designed around a missing layer in the current MoonBit ecosystem: a reusable poster/template/rendering pipeline above lower-level SVG and graphics utilities.

## What Was Referenced

- MoonBit official language and toolchain documentation
- MoonBit package / test / module configuration documentation
- MoonBit community GitHub workflow templates
- competition guide and submission requirements
- mooncakes ecosystem keyword checks to reduce overlap with mature existing projects

## What Was Not Reused

- no direct copy of mature poster-generation business logic from existing MoonBit repositories
- no transplant of another project's commit history
- no synthetic co-author or virtual contributor identity

## Repository Policy

- single real contributor identity only
- meaningful incremental commits
- generated public interfaces tracked explicitly via `moon info`
- CI aligned with actual local verification commands
